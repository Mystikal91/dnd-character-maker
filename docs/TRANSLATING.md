# Translating

All texts live in `locales/<language>/`. English (`en`) is the source language; every other
language is a translation of it. A missing translation falls back to English, so a language can
be translated little by little.

```
locales/
  en/ui.json              interface texts
  en/srd51/*.json         rules texts (names, descriptions) of the SRD 5.1 pack
  it/ui.json              Italian interface
  it/srd51/*.json         Italian rules texts (added as they are translated)
```

Every file is a flat JSON object. Interface keys look like `sheet.armorClass`; rules keys look
like `fireball.desc` (`<entry slug>.<field>`). Text may contain `{placeholders}`, which must be
kept exactly as written (a test checks this for the interface texts).

## Weblate setup

Use one Weblate project for the whole app, and add components with the **Add-on "Component
discovery"** so new files appear on their own:

| Setting | Value |
| --- | --- |
| Version control system | Git, repository `https://github.com/Mystikal91/dnd-character-maker.git`, branch `main` |
| File format | JSON file (`json`) |
| Regular expression to match translation files | `locales/(?P<language>[^/.]*)/(?P<component>.*)\.json` |
| Source language | English |
| Language code style | Default (`it`, `en`) |
| Monolingual | Yes: the template (source) file is `locales/en/<component>.json` |
| Push branch | A separate branch, e.g. `weblate`, merged by pull request |
| Edit base file | No: only the English files in the repository define the source texts |

Notes:

- `locales/en/srd51/*.json` is generated by `npm run data:srd51`; never translate or edit it by
  hand. Change the generator instead.
- Official translations of the rules (if their license allows distributing them) should be
  imported once and then **locked** in Weblate, so contributors only review and fix them.
- To add a language: create `locales/<code>/ui.json` (Weblate can do it), add the code to
  `LANGUAGES` in `src/app/language.logic.ts`, and import its interface file in
  `src/i18n/ui.ts`.

## Checking a translation locally

```bash
npm test
```

The language tests fail when a translated interface file has a key English does not have, or
changes the `{placeholders}` of a text.
